# Club Fair Generator Prompt

Create or revise club-fair messaging using the recruitment files and club context.

The output must directly answer: Why should I join? What will we do? How is it interactive? Can I join with no experience? What if I already code?

Lead with a 60–90 second hands-on Java micro-demo in which a visitor changes one value or choice and sees new output. Promise a beginner-first path, collaborative builds, optional algorithm/competition challenges, and no public ranking. Avoid jargon, exaggerated outcomes, unverified dates, and personal data.

Deliver a 30-second pitch, one-pager copy, FAQ changes, demo instructions with fallback, and a single call to action whose time/location remain `TBD` until verified. Review against `docs/CONTENT_STANDARDS.md`.
