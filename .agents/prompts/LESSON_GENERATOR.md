# Lesson Generator Prompt

Create one club lesson using `templates/LESSON_PLAN_TEMPLATE.md` plus the slide, exercise, solution, and exit-ticket templates.

Inputs: meeting number/title, prerequisites, target skill, duration, available devices, and any verified logistics.

Requirements:

- Read the scope, prerequisite map, readiness gates, and content standards first.
- Use one observable objective and a tiny motivating build.
- Keep each explanation/demo block to 8–10 minutes maximum and reserve at least half the session for coding.
- Include core, support, and stretch variants; no member labels.
- End in visible runnable code, include expected output, common errors, tests, solution notes, and a recovery activity.
- Use accurate Java terminology and compile all Java examples.
- Update lesson/code indexes. Keep unknown facts `TBD`; include no private student information.

Return files changed, compilation command/results, and open `TBD` items.
