# Slides Outline: [Lesson]

Keep slides visual and brief; slides support coding rather than replace it.

1. **Welcome/build preview** — show what will run by the end.
2. **Objective and prerequisites** — one sentence each.
3. **Predict** — tiny code/output question.
4. **Concept model** — one diagram or example; define only needed terms.
5. **Live demo** — edit, predict, run, debug; explanation block ≤10 minutes.
6. **Build instructions** — three visible milestones.
7. **Choice card** — support / core / stretch without member labels.
8. **Debug card** — common message, where to look, first action.
9. **Demo and exit** — run it, share optionally, submit anonymous feedback.

Add speaker notes for expected misconceptions, timing, accessibility, and the fallback environment. Link starter and solution files.
