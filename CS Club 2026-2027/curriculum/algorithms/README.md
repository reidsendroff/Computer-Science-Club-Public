# Algorithms Path

Algorithms are introduced after Java fluency evidence, not as disconnected tricks.

## Sequence and gates

1. **Linear search, min/max, counting** — arrays/ArrayList, indexing, loops, conditionals, methods.
2. **Binary search** — Java Foundations Gate, sorted input, linear search, interval tracing. Earliest placement: Weeks 11–12.
3. **Sorting/comparison** — arrays/ArrayList, comparison logic, methods, loop invariants.
4. **Stack and queue** — objects, collections, state changes, method contracts.
5. **Map and set** — collections, loops, equality concept, key/value modeling.
6. **Two pointers** — arrays/ArrayList, safe indexing, loops, conditionals, and sorted-data reasoning where the approach requires it.
7. **Recursion or explicit iterative state** — methods, parameters/returns, conditionals, call-stack/base-case tracing.
8. **Graph representation** — collections, maps/sets, references, vertices/edges, adjacency lists.
9. **BFS and DFS** — Graph Traversal Gate, visited-state invariant, queue or stack/recursion.
10. **Dijkstra** — weighted graphs, BFS contrast, nonnegative edge weights, priority queue.
11. **Dynamic programming** — subproblem/state definition, base cases, arrays/maps, recursion or staged iteration.

Each lesson must use the meeting standard: hands-on majority, core/support/stretch, runnable finish, exit ticket, and recovery path. Competition use is optional and only after rules/dates are officially verified.
