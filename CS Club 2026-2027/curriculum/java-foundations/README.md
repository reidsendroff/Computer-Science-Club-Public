# Java Foundations

This ten-meeting common core follows the [scope and sequence](../SCOPE_AND_SEQUENCE.md). No lanes or permanent skill groups are used during this phase.

## Teaching approach

- Begin with a runnable scaffold, then reveal syntax as it becomes useful.
- Treat `public static void main(String[] args)` as the supplied entry point in Week 1; explicitly unpack its pieces in Weeks 5, 6, and 8.
- Use methods as the Java term. Distinguish local variables, parameters, instance fields, and static fields.
- Prefer private state with public behavior; use `static final` constants for shared constants.
- Make debugging visible: predict, run, read the message, change one thing, rerun.
