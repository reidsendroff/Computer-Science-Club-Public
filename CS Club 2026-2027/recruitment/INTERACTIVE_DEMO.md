# Club Fair Interactive Demo: Remix and Run

Length: 60–90 seconds per visitor.

## Promise

“Change one value, run a real Java program, and make the output yours.”

## Setup

- Open the tested [club fair example](../../code/club-fair/ClubFairDemo.java) in the verified local or browser environment.
- Display the editor and output side by side.
- Prepare three prompt cards: favorite activity, energy level, and surprise mode.
- Browser environment and QR code: `TBD` after school-device/privacy verification.

## Visitor flow

1. Ask the visitor to choose or type one mood number from 1–3.
2. Let the visitor press Run.
3. Read the personalized activity message together.
4. Ask: “What would you change next?”
5. Point to the signup call to action (`TBD`).

## Support and stretch

- Support: a leader points to the exact value to edit.
- Core: visitor changes the value and predicts the result.
- Stretch: visitor adds a fourth case or changes the method's message.

## Fallback

If the network or compiler fails, use printed code/output cards. The visitor chooses an input, traces the matching branch, and places a new output card; leaders must still demonstrate a tested local run when possible.

## Safety

Do not collect names in the code, photograph screens with names, or require a public account.
