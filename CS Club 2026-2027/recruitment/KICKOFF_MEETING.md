# Kickoff Meeting = Week 1: First Java Program

The club fair is a separate recruitment event using the [one-minute fair demo](INTERACTIVE_DEMO.md). This kickoff is the first regular member meeting. No reusable Week 1 starter/base package is stored in the repository.

Goal: every member makes a Java program visibly change and knows Week 2 continues the beginner-first sequence.

## 60-minute plan

- 0:00–0:05 — welcome; “no experience required”; show three finished mini-projects
- 0:05–0:13 — live remix of a small club-introduction program; identify source, string literal, `println`, compile, and run
- 0:13–0:35 — members create, personalize, and run a small Java program from facilitator steps
- 0:35–0:38 — read and repair one missing-quote or semicolon error
- 0:38–0:50 — choice: finish with support, add a multi-line story, or help test a partner's version
- 0:50–0:56 — voluntary runnable demos
- 0:56–1:00 — complete a short anonymous exit ticket and preview the next meeting (`TBD`)

## Preflight

- Verify local and zero-install paths on school devices.
- Prepare pair-and-rotate and printed fallback materials.
- Keep signups in a school-approved private system.
- Do not use a graded placement test at kickoff.
- Test the facilitator-led example before members arrive without committing a reusable starter or solution base.

## Visible finish

Each member runs a personalized club introduction or tiny story and can point to the edit that changed its output.

## Recovery

Switch setup paths after 10 minutes, provide typed facilitator steps or pair-and-rotate support, and complete an equivalent recheck no later than the start of Week 2. Do not create a separate track.
