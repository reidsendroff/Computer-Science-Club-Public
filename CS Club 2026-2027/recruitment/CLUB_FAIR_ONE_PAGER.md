# Computer Science Club: Make Something Run

## Why join?

Because coding becomes fun when you can make an idea work, show it to someone, and improve it together. You can arrive with zero experience. We start at the beginning and help everyone leave the first meetings with real Java programs that run.

## What will we do?

- Build small games, tools, and interactive programs in Java
- Learn to read errors and debug without panic
- Work in pairs and teams, remix code, and demo what we made
- Grow from Java fundamentals into projects and algorithm challenges
- Try optional programming competitions after the needed skills are in place

## Is it interactive?

Yes. Explanations are short; most meeting time is spent coding. Every activity has a main build, extra support, and an optional stretch. Every meeting ends with something visible and runnable.

## What if I have never coded?

Perfect. The first ten meetings form one shared Java course beginning with a first runnable program, variables, choices, loops, and methods. Setup help and a zero-install fallback are provided.

## What if I already code?

Add features, tests, design constraints, and performance improvements; help review code; lead a demo; and progress toward advanced projects and competitions. You will not be limited to beginner exercises.

## Try it now

At the fair, change one line in a tiny Java mood-message program, run it, and watch the output change. It takes about one minute.
