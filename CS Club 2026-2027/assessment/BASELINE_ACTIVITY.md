# Baseline Activity: Make It Yours

Purpose: learn what support to prepare without grading or grouping members. Run during kickoff or Week 1.

## Activity

Give everyone a runnable greeting program. Ask them to:

1. run it once;
2. change the message and run it again;
3. add a second printed line;
4. if desired, create a variable or ask for input.

Offer exact-step support, the core three edits, and optional stretch. End by asking each member to point to the change that affected the output.

## Record only aggregate signals

- Could run with the local/browser/pair fallback
- Produced the core visible change
- Requested more setup or syntax support
- Chose optional stretch
- Anonymous pace and fun response

Do not store names, scores, attendance, or individual observations in this repository. The result changes Week 2 support, not membership status.
