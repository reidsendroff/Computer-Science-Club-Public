# Anonymous Weekly Feedback

Collect through an adviser-approved anonymous method (`TBD`) and discard raw free text after leaders extract non-identifying themes under school policy.

Ask:

1. Pace: too slow / about right / too fast
2. Today felt: frustrating / okay / fun
3. I can run and explain today's core program: not yet / with help / independently
4. Next time I want: more examples / more build time / more challenge / partner help
5. One thing to keep or change (optional; remind students not to identify anyone)

Publish only aggregated responses large enough to protect identity. Never connect answers to names, academic grades, or attendance.
