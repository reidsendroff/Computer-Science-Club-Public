# Lesson Review Checklist

Approve only when all required items pass.

## Sequence and learning

- [ ] Prerequisites match the prerequisite map and have prior evidence.
- [ ] One observable objective and a visible runnable finish are stated.
- [ ] Direct-teaching blocks are each 8–10 minutes or less.
- [ ] Hands-on time is at least half the meeting.
- [ ] Core, support, and stretch are present without member labels.
- [ ] Recovery path and exit ticket are included.

## Java and materials

- [ ] Terminology, code, expected output, and error explanations are accurate.
- [ ] Examples compile/run; filenames match public classes.
- [ ] Starter and solution paths are clear; no generated `.class` files are committed.
- [ ] Early `main` scaffold is either deferred explicitly or explained using taught concepts.
- [ ] `Scanner` input mixing is handled where relevant.

## Safety and operations

- [ ] Local and zero-install/pair fallback are usable.
- [ ] Links resolve; dates/logistics are official or `TBD`.
- [ ] No resumes, contacts, rosters, attendance, academic grades, individual progress, raw feedback, credentials, rankings, permanent labels, or unapproved officer grade levels appear.
- [ ] The lesson and code indexes are updated.
