# Meeting Production Workflow

## T–7 days: assign and frame

- Primary owner confirms objective, prerequisites, runnable finish, and recovery path.
- Backup owner verifies device/browser assumptions.
- Unknown logistics stay `TBD`.

## T–5 days: draft

- Create lesson plan, slides outline, exercise set, solution/editorial, exit ticket, and Java files from templates.
- Time direct teaching blocks at 8–10 minutes maximum and hands-on work at 50% minimum.

## T–3 days: independent review

- A different leader runs the review checklist.
- Compile/run examples from a clean folder; test support and stretch variants.
- Check links, privacy, prerequisites, and expected output.

## T–1 day: publish and preflight

- Resolve review findings and update lesson/code indexes.
- Test on a school device and the verified fallback.
- Publish the public objective and materials; keep rosters and reminders with personal data in the private approved system.

## Meeting and T+1 day

- Run the visible finish and anonymous exit signal.
- Record only aggregate results.
- Use the retrospective to choose one improvement and log any durable decision.
