# Computer Science Club

A public planning and teaching repository for a welcoming, hands-on Computer Science Club. The 2026–2027 program starts with ten shared meetings of Java fundamentals, then moves into algorithms only when members are ready.

## Start here

- [2026–2027 program hub](CS%20Club%202026-2027/README.md): agenda, curriculum, leadership, recruitment, and operations
- [Curriculum scope and sequence](CS%20Club%202026-2027/curriculum/SCOPE_AND_SEQUENCE.md): the week-by-week learning path
- [Club fair one-pager](CS%20Club%202026-2027/recruitment/CLUB_FAIR_ONE_PAGER.md): what the club offers and why to join
- [Agent instructions](AGENTS.md): rules for humans and AI assistants creating materials
- [Contribution guide](CONTRIBUTING.md): how to add or review content

## Repository map

- `CS Club 2025-2026/` — privacy-reviewed historical materials; sensitive originals remain only in the private repository
- `CS Club 2026-2027/` — current program source of truth
- `.agents/prompts/` — reusable content-generation and review prompts
- `docs/` — stable club context and content standards
- `lessons/` and `code/` — indexes for published meeting materials and runnable examples

This repository is public. Do not add personal contact details, résumés, attendance, academic grades, individual progress data, or unapproved officer grade levels.
